## 📖 نبذة عن المشروع (Overview)

هذا المشروع عبارة عن صفحة هبوط تسويقية متكاملة (Marketing Landing Page) مصممة بعناية فائقة لدعم برنامج السفراء لمنصة **Money Fellows** (الخاضعة لإشراف المختبر التنظيمي بالبنك المركزي المصري). تهدف الصفحة إلى تسهيل وصول المستخدمين لكود الخصم، وتوضيح خطوات التسجيل، وحساب القسط الشهري وصافي التكلفة أو التوفير بناءً على مبلغ القبض، المدة، ودور القبض المختار.

## ✨ المميزات والخصائص التقنية (Key Features)

* 🎨 **تصميم عصري ومتجاوب (Tailwind CSS):** واجهة مستخدم مظلمة (Dark Theme) جذابة ونظيفة تتوافق تماماً مع الهواتف الذكية والأجهزة اللوحية والكمبيوتر.
* 🧮 **حاسبة الجمعية التفاعلية (Interactive Calculator):** أداة ذكية لحساب القسط الشهري، رسوم الدور، تأثير خصم الكود (300 جنيه)، وإجمالي ما ستدفعه بدقة بناءً على مدخلات المستخدم.
* 📋 **نسخ سريع وسهل للكود:** أزرار مدمجة لنسخ كود الخصم (`92962874`) بنقرة واحدة مع إظهار إشعار تأكيد بصري (Toast Notification).
* 📊 **جداول رسوم وخصومات تفصيلية:** عرض تفصيلي لنسب رسوم الأدوار الأولى وخصومات الأدوار الأخيرة لمختلف مدد الجمعيات (6، 10، و12 شهراً).
* 🎥 **مكتبة فيديوهات الشرح والبحث:** قسم مخصص لفيديوهات يوتيوب الشارحة لكافة تفاصيل التطبيق والاشتراك والسداد، مزود بمحرك بحث فوري وتصنيف بالأقسام.
* ❓ **قسم الأسئلة الشائعة (FAQ):** إجابات تفصيلية ومنظمة عن كافة استفسارات المشتركين المحتملين مدعومة ببيانات منظمة (`Schema.org FAQPage`).
* ✨ **خلفية تفاعلية متطورة (Canvas Star/Net Animation):** تأثيرات بصريّة حركية في الخلفية تتفاعل بسلاسة مع حركة مؤشر الماوس واللمس.
